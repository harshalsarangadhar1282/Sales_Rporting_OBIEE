# OBIEE Reporting Project

## Objective
Create an OBIEE-based sales reporting dashboard using Sales_Fact, Product_Dimension, and Region_Dimension tables.

## Subject Area
Sales Analysis

## Dimensions
- Region
- Product
- Sales Rep
- Order Date

## Measures
- Sales Amount
- Quantity
- Unit Price

## Report Layout
1. Sales by Region
2. Sales by Product
3. Sales by Sales Rep
4. Monthly Sales Trend
5. Top 10 Products

## Dashboard Prompts
- Region
- Product
- Sales Rep
- Order Date

## OBIEE Steps
1. Import CSV files into database or use Excel as data source.
2. Create Physical Layer with Sales_Fact, Product_Dimension, Region_Dimension.
3. Create Business Model and Mapping Layer.
4. Create Presentation Layer with Subject Area named Sales Analysis.
5. Create Analysis using Sales Amount, Region, Product, Sales Rep.
6. Add filters and prompts.
7. Create dashboard and add reports.
8. Save and publish dashboard.

## Resume Line
Created an OBIEE-based sales reporting dashboard using dimensional modeling, SQL-based data preparation, and interactive dashboard prompts for regional and product-level sales analysis.
