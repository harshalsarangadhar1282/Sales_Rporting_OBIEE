# OBIEE Reporting Project

## Files
- Sales_Fact.csv : main sales data
- Product_Dimension.csv : product details
- Region_Dimension.csv : region details
- OBIEE_SQL_Script.sql : SQL queries
- OBIEE_Report_Design.md : report design
- Dashboard_Mockup.txt : dashboard layout
- README.md : instructions

## How to Use
1. Import CSV files into Oracle database or use them as OBIEE data source.
2. Create Physical Layer using the CSV files.
3. Create Business Model and Mapping Layer.
4. Create Presentation Layer with Subject Area Sales Analysis.
5. Create Analysis using Sales Amount, Region, Product, Sales Rep.
6. Add prompts and filters.
7. Create dashboard and add reports.
8. Save and publish dashboard.

## Resume Line
Created an OBIEE-based sales reporting dashboard using dimensional modeling, SQL-based data preparation, and interactive dashboard prompts for regional and product-level sales analysis.
